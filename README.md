# Arshaka Cipta Adhidaya — Company Profile Landing Page

Landing page statis untuk CV. Arshaka Cipta Adhidaya.

## Identitas visual
- Font: Montserrat
- Biru utama: `#003049`
- Orange utama: `#F58020`

## Fitur
- Hero section dengan animasi dan parallax
- Profil perusahaan
- Visi & misi
- Bidang usaha dan kategori jasa
- Showcase proyek aktual berdasarkan folder dokumentasi yang diberikan
- Filter proyek: Semua, Jalan, Bangunan, TPT
- Lightbox dokumentasi proyek dengan thumbnail dan navigasi keyboard
- Responsive untuk desktop, tablet, dan mobile
- Scroll reveal, progress bar, mobile navigation, dan reduced-motion support

## Dokumentasi proyek
Dokumentasi yang disertakan berasal dari ZIP proyek yang dikelompokkan berdasarkan folder:
1. Jalan Jabong Cidahu — 4 foto
2. Pembangunan LAB Komputer SDN Lengkong — 4 foto
3. Pembuatan Jalan Cidogdog — 3 foto
4. Pembuatan Jalan Cikur — 4 foto
5. Pembuatan Jalan Gardu Sayang – Mayang — 4 foto
6. Pembuatan Jalan Puri – Subang — 3 foto
7. Pembuatan Jalan Sembung – Sumurgintung — 4 foto
8. TPT Sarbuaya — 6 foto

Total: 32 dokumentasi.

File HEIC dari dokumentasi asli dikonversi ke WebP agar dapat ditampilkan secara konsisten di browser dan menjaga ukuran website tetap lebih ringan.

## Menjalankan
Tidak membutuhkan Node.js atau build tool. Buka `index.html` melalui web server statis atau deploy langsung ke Vercel.
